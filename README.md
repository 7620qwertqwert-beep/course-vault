## 📤 我要传资料

打开 [上传页](http://82.156.233.65:8080/docs/upload.html) → 选学院 / 专业 / 课程 → 填年份学期、选资料类型、填标题（可选）：只写资料名 → 拖文件提交。

文件会自动命名为「年份-标题」；标题留空就用资料类型名，不用自己改名。

最多 5 个文件、单个 ≤50MB、zip ≤20MB、合计 ≤100MB；字段、扩展名和排错见 [CONTRIBUTING.md](CONTRIBUTING.md)，卡住了看这个：[新手上传教程](docs/新手上传教程.md)。

> 命名：新文件按「年份-标题」，旧文件「年份-类型-课程」仍兼容，不做批量改名。详见 [CONTRIBUTING.md](CONTRIBUTING.md)。
>
> 不能传：含姓名、学号、身份证、联系方式，未授权课件/试卷，正版教材 PDF。详见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 📂 目录结构

```
courses/
├── 公共课/
│   └── 高等数学/                  # 全校通用：两层
│       ├── README.md              # 课程卡片
│       ├── 笔记/
│       ├── 课件/
│       ├── 试卷/
│       ├── 作业/
│       ├── 实验报告/
│       └── 复习资料/
└── 专业课/
    └── <学院名>/                  # 例如：医学院
        └── <专业名>/              # 例如：康复治疗学
            └── <课程名>/          # 例如：康复医学概论
                ├── README.md
                ├── 笔记/
                ├── 课件/
                ├── 试卷/
                ├── 作业/
                ├── 实验报告/
                └── 复习资料/
```

> 公共课两层（课程/资料），专业课四层（学院/专业/课程/资料）。同名课程在不同专业各建一份。

## 🤖 自动检查

任何 PR / 自动归档都会跑检查，不过关不能合并：`scripts/check.sh`（目录、命名、体积、文本个人信息）、`scripts/build_index.py --check`（索引与目录一致）、单文件 50MB / 单 PR 100MB 上限。`main` 不能直推、不能强推、不能删。
