## ⬆️ 上传资料（按推荐顺序）

| 顺序 | 通道 | 适合谁 | 怎么走 |
|---|---|---|---|
Issues → New issue → 选「上传资料」模板 → 按模板填课程名称、开课学院、所属专业、年份学期、资料类型 → 把文件拖进正文 → 提交；维护者加 `approved` 后机器人自动归档
| 方式一（备选） | 直接发给维护者 | 不方便注册账号，或手机加不了附件 | 在班级/学院群问一句，或开 Issue 留言；写清课程、学院/专业、年份学期、资料类型 |
| 方式二（备选 · 进阶，可选） | Fork + Pull Request | 想自己控制文件位置、愿意学一点 Git | Fork → 在自己的副本上传 → 回官方仓库开 PR |
| 方式三（备选 · 开发者用） | 本地 git 命令 | 会用命令行的开发者 | clone → 放文件 → commit → push（无权限就推到自己的 fork 再开 PR） |

### 方式零：填「上传资料」表单（推荐）

1. 仓库顶部 **Issues** → **New issue**，先选你所在**学院**的模板（例如 **「上传资料 · 医学院」**）→ **Get started**。学院已经预填好；进去后先选 **所属专业**，再填 **课程名称**。
2. 只有一个 **「上传资料」** 模板，进去照着填就行。
3. **课程名称** 照仓库里的目录写，写成 **「专业 · 课程名」** 最好认（例：`康复治疗学 · 康复评定学`），只写课程名也能对上。再填 **开课学院**、**所属专业**。写错不要紧，机器人会拦下并给出最近似的写法。
4. 填 **年份学期**（写成 `2025秋` 这种格式，例：`2023春`、`2026秋`），再选 **资料类型**（决定资料放进课程下哪个子目录）。
5. 把文件拖进 **附件** 框：最多 5 个、每个 ≤50MB；手机加不上附件就走方式一。
6. 勾选确认 → **提交**。维护者加 `approved` 后机器人自动归档；写错会收到失败提示和正确写法，改好再触发一次即可。

> 课程名称、开课学院、所属专业都照仓库里的目录名写；仓库里没有这门课，说明还没建目录：开个 Issue 说一声。

> 填表只能给**已有课程**加资料；仓库里还没有的课，先把课程信息发给维护者建目录。

> ⚠️ Issue 是公开的：含姓名、学号、手机号、身份证的页，先删掉或涂掉再传。

### 方式一：直接发给维护者（备选）

不方便注册账号也能传。在班级/学院群问一句，或开 Issue 留言，写清 **课程全名 + 学院/专业 + 年份学期 + 资料类型**；维护者替你命名、归档、提交。

### 方式二：Fork + Pull Request（备选 · 进阶，可选）

1. 官方仓库右上角 **Fork** → 得到自己的副本。
2. 在自己的副本里进目标文件夹 → **Add file** → **Upload files** → **Commit changes**。
3. 回官方仓库 → **Pull requests** → **New pull request** → 选自己的分支 → **Create**。
4. 维护者审核合并。全程网页，不用命令行。

### 方式三：本地 git（备选 · 开发者用）

```bash
git clone https://gitee.com/youliboshi/course-vault.git
cd course-vault
# 把文件放进对应课程目录，文件名按下面的规范
git add .
git commit -m "add: 高等数学 2025秋 期末A卷"
git push   # 没权限就推到自己的 fork，再开 PR
```

## 📝 命名规范

```
<年份><学期>-<类型>-<描述>.<后缀>
2025秋-期末-高等数学A卷.pdf
2026春-笔记-高等数学-第一章极限.md
2025秋-实验报告-大学物理-测量数据处理.docx
```

| 项 | 规则 |
|---|---|
| 学期 | `春` / `秋` |
| 类型 | `期末` `期中` `笔记` `作业` `实验` `实验报告` `课件` `复习` `答案` |
| 禁止 | 姓名、学号、老师私人联系方式 |

> 填表不用自己命名，机器人会按规范重命名；Fork / git 上传才需要自己改。

## 🚫 不要上传

- 带姓名、学号、身份证号、联系方式的文件（页眉页脚、文档属性、截图角落都算）。
- 老师明确说不得外传的课件、讲义、未公开试卷。
- 正版教材 PDF（只登记书名、作者、版次、ISBN）。
- 单个超过 50MB 的文件（改用网盘链接，并在课程卡片登记）。

## 🤖 自动检查

任何 PR / 自动归档都会跑检查，不过关不能合并：`scripts/check.sh`（目录、命名、体积、文本个人信息）、`build_index.py --check`（索引与目录一致）、单文件 50MB / 单 PR 100MiB 上限。`main` 不能直推、不能强推、不能删。
