# 他校参考

收录周边高校**官网公开发布**的人才培养方案等规范性文件，供本校同学了解课程体系、考研与转专业参考。

- 来源：各校教务处官网公开发布的页面与附件（信阳职业技术学院、南阳理工学院等）
- 抓取时间：2026-11-04
- 版权归原学校所有，本站仅作学习参考，不作为官方依据；如原校要求下架，请联系维护者删除
- 资料按「信阳师范大学 2026 秋季现行专业目录」无关，属于外部参考，请勿与本专业课程资料混用

## 目录与命名

- 结构固定三层：`他校参考/<学校名>/<类别>/<文件>`，不允许再嵌套；类别目前有 `培养方案`
- 不要直接放在 `他校参考/` 根下或学校目录下，`scripts/check.sh` 会把这两种情况判为错误
- 文件名按 `YYYY春/秋-类别-描述.pdf`，例如 `2021秋-培养方案-临床医学专业.pdf`
- 本目录不参与 `INDEX.md`（索引只统计 `公共课` / `专业课` 的 859 门课）
