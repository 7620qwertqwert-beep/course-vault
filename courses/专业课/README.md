# 专业课

这里放**专业课**的资料，一门课一个文件夹。

目前还是空的——因为还没人往里放东西。

## 怎么往这里加一门课

在电脑上跑（或让小夏跑）：

```bash
python3 scripts/new_course.py
```

按提示输入课程名、类别选「专业课」，它会自动建好文件夹和课程卡片。

手动也行：复制 `_template/` 文件夹 → 改名成课程名 → 放进这个目录。

## 加完之后长这样

```
专业课/
├── 数据结构/
│   ├── README.md      ← 课程卡片
│   ├── notes/
│   ├── slides/
│   ├── exams/
│   └── homework/
└── 计算机组成原理/
    └── ...
```
