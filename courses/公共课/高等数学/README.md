## 难度与避坑

- 难度打分：★★★★☆
- 挂科率体感：全校公共课里最高的一门，别心存侥幸
- 点名/签到频率：较高，缺课影响平时分
- 作业量：每节都有，抄答案没用，考试不考原题
- 最容易踩的坑：**极限与导数定义的理解**、**级数收敛判别**、**不定积分技巧题**
- 转专业/考研相关：考研数学一/二的基础，学好这门后面全是复利

## 复习建议

- 期末重点章节：极限、导数应用、不定积分、定积分应用、级数
- 出题习惯：计算题占大头，证明题 1~2 道
- 建议复习时长：考前 2 周，每天 2 小时
- 最有用的一份资料：历年期末卷（题型重复率高）
