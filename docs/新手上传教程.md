# 新手教程：第一次上传，3 分钟搞定

> 前提：有 GitHub 账号。没有就先去 github.com 注册，只需要邮箱。

## 路线 A：网页拖拽（不用装任何东西，推荐）

1. 手机或电脑浏览器打开本仓库页面
2. 点进要放的文件夹，例如 `courses/公共课/高等数学/exams/`
3. 右上角 `Add file` → `Upload files`
4. 把文件拖进去（手机就点"选择文件"）
5. 下方 Commit changes 框里写：`add: 高等数学 2025秋 期末A卷`
6. 点绿色 `Commit changes`

完成。文件已经在库里的，别人打开就能下载。

## 路线 B：Git 命令（一次配好，以后批量传）

```bash
# 1. 克隆到本地
git clone https://github.com/<你的账号>/course-vault.git
cd course-vault

# 2. 第一次用要配身份（只配一次）
git config user.name "你的名字"
git config user.email "你的邮箱"

# 3. 把文件拷进对应目录后
git add .
git commit -m "add: 高等数学 2025秋 期末A卷"
git push
```

> 现在 GitHub 不再支持密码推送，`git push` 提示输入密码时，要填 **Personal Access Token**（在 GitHub → Settings → Developer settings → Personal access tokens 生成，勾 `repo` 权限），不是登录密码。

## 路线 C：什么都不想学 → 开 Issue

1. 仓库页 → `Issues` → `New issue`
2. 标题：`[上传] 高等数学 2025秋 期末A卷`
3. 正文贴网盘链接（建议 7 天有效）或直接拖文件进输入框
4. 提交，等维护者归档

## 常见问题

**Q：传错了想删怎么办？**
打开该文件 → 右上角垃圾桶图标 → Commit，就删了。历史记录里还能找回。

**Q：能不能传老师的完整 PPT？**
可以，但老师明确说了不许外传的不要传。

**Q：我的笔记很丑，值不值得传？**
值得。丑笔记里标出的"这里老师说了必考"，比漂亮笔记有用十倍。

**Q：会不会有人拿我的资料卖钱？**
本库采用 CC BY-NC-SA 4.0（非商业），商用属侵权，可投诉下架。但技术上无法百分之百阻止，传之前心里有数。
