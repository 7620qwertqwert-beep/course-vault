# 新手教程：第一次上传，10 分钟搞定

> **前提一**：有 GitHub 账号（没有就先去 github.com 注册，只要邮箱）。
> **前提二**：你**不是**这个仓库的成员，所以**不能直接点 Add file**。普通同学推荐走**路线 C：填表**，不用 Fork；想自己控制文件位置，再走**路线 A：Fork + 网页拖拽**。

> ⚠️ **上传前想清楚**：GitHub 上的东西是公开的、可被存档的。「删掉文件」不等于「删掉历史」——文件一旦提交过，就留在 Git 历史里，别人的 fork 和搜索引擎缓存也可能还在。**含姓名、学号、电话、身份证的材料，一开始就别传。**

## 路线 0：完全不用碰 GitHub（最省事，推荐给大多数同学）

> 💡 **不用管 INDEX.md**。你传完资料后，INDEX 里的「资料数 / 状态」会自动由维护者刷新；CI 不会因为这个拦你。唯一会被拦的是**文件名不规范**（要写成 `2025秋-笔记-课程名.md` 这种）和**动了课程目录结构**。
你只需要做一件事：**把文件发给资料库维护者**。

- 找维护者：班级群 / 学院群里问一句「课程资料库谁来收资料」，或者在本仓库开一个 Issue 留言（见路线 C）
- 发送时写清楚：**课程全名 + 所在学院/专业 + 年份学期 + 资料类型**（笔记/课件/试卷/作业/实验报告）
- 剩下的事——建目录、改规范文件名、提交、过 CI——都由维护者做，你一步都不用点

> 发之前检查一遍：**含姓名、学号、手机号、身份证的页要删掉或涂掉**。GitHub 上的东西是公开的，删文件不等于删历史。

## 路线 A：Fork + 网页拖拽（进阶选项，不学也能传）

1. 打开官方仓库，**右上角点 `Fork`** → 你账号下会出现一份你自己的副本
2. 在**你自己那份**里点进目标文件夹：公共课例如 `courses/公共课/高等数学/试卷/`；专业课按「学院 → 专业 → 课程」进入，例如 `courses/专业课/医学院/康复治疗学/人体解剖学/试卷/`
3. 右上方 `Add file` → `Upload files`
4. 选文件（手机就点"选择文件"）
5. 下面 Commit changes 框里写：`add: 高等数学 2025秋 期末A卷`
6. 点绿色 `Commit changes`
7. 回到**官方仓库**，点 `Pull requests` → `New pull request` → 选你刚提交的分支 → `Create pull request`

维护者看到后合并，你的资料就进官方库了。

> 如果你已经被加为仓库协作者，可以跳过 Fork，直接在第 2 步上传。

## 路线 C：填一张表就行（不用 Fork、不用懂路径）

1. 仓库顶部 `Issues` → `New issue` → 选「上传资料」表单
2. 按顺序填写或选择：**课程类别 → 开课学院 → 所属专业 → 课程名称 → 年份学期 → 资料类型**
   - 公共课：学院、专业留空即可；课程名直接写课名（如 `高等数学`）
   - 专业课：学院、专业必须选，课程名必须与仓库里的课程文件夹名完全一致（如 `康复医学概论`）
3. **把文件直接拖进「附件」框**（最多 5 个，每个不超过 50MB；zip 不超过 20MB）
4. 勾选「文件里不含本人或他人的姓名、学号、手机号、身份证号」，提交 Issue
5. 维护者确认后给 Issue 加 `approved` 标签
6. 机器人自动下载、按 `年份学期-类型-课程名` 命名、归档到 `courses/`，并开一个 PR
7. PR 的「结构与内容检查」CI 通过后，由维护者合并

> 全程**不需要 Fork、不需要知道目录层级、不需要改 INDEX.md**。表单里的学院和专业都是下拉选项，课程名输入框有示例；附件直接拖拽即可。

> ⚠️ Issue 是公开的。不想公开挂文件，就在 Issue 里只写清单并注明「文件私发」，维护者再联系你。含姓名、学号、联系方式的页请先删掉或涂掉。

## 路线 B：Git 命令（一次配好，以后批量传）

```bash
# 1. 克隆到本地
git clone https://github.com/7620qwertqwert-beep/course-vault.git
cd course-vault

# 2. 第一次用要配身份（只配一次）
# 注意：这两项会永久写进每一条公开提交记录里，是所有人都能看到的
git config user.name "你的GitHub昵称"      # 别填真实姓名
git config user.email "你的GitHub邮箱"     # 建议用 xxx@users.noreply.github.com

# 3. 把文件拷进对应目录后
git add .
git commit -m "add: 高等数学 2025秋 期末A卷"
git push
```

> 现在 GitHub 不支持密码推送，`git push` 提示要密码时填的是 **Personal Access Token（PAT）**，不是登录密码。

**别用 classic token（勾 `repo` 的那个）**——它等于把你名下所有仓库的写权限交出去，一旦泄露就是灾难。用 **Fine-grained token**：
GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
- Repository access：只选 **你 fork 出来的那一个仓库**
- Permissions：只给 **Contents: Read and write**
- Expiration：7 天足够传完一次

传完就删掉这个 token。

## 常见问题

**Q：传错了想删怎么办？**
打开该文件 → 右上角垃圾桶图标 → Commit，就删了。

但**注意**：这只删掉「现在这一版」，文件仍然留在 Git 历史里，别人翻历史、翻 fork 都能看到。如果删的是含个人信息的文件，光是删不够，要走[下架流程](../TAKEDOWN.md)。

**Q：能不能传老师的完整 PPT？**
可以，但老师明确说了不许外传的不要传。

**Q：我的笔记很丑，值不值得传？**
值得。丑笔记里标出的"这里老师说了必考"，比漂亮笔记有用十倍。

**Q：会不会有人拿我的资料卖钱？**
本库采用 CC BY-NC-SA 4.0（非商业），商用属侵权，可投诉下架。但技术上无法百分之百阻止，传之前心里有数。
