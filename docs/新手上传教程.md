# 新手上传教程：第一次上传，照着点就行

> 前提：不用会 Git，也不用 Fork。主通道是**路线 0：填表**。上传前先记住：GitHub 是公开的，删文件不等于删历史；含姓名、学号、电话、身份证的页，先删掉或涂掉。

## 路线 0：填「上传资料」表单（推荐）

1. 打开仓库首页 → **Issues** → **New issue** → 选 **「上传资料」** → **Get started**。
2. **课程类别**：公共课 / 专业课 二选一。
   - 公共课：**开课学院**、**所属专业**留空。
   - 专业课：**开课学院**选 24 个学院之一；**所属专业**选「学院·专业」，例如「医学院·康复治疗学」。
3. **课程名称**：照课程卡片填，必须和仓库文件夹名一字不差。例：公共课填 `高等数学`；专业课填 `康复医学概论`。仓库里还没有的课，先走路线 1 让维护者建目录。
4. **年份学期**：选 `2025秋` 这类；选「其他」就在附件框写明 `20xx春/秋`。**资料类型**：笔记 / 课件 / 试卷 / 作业 / 实验报告 / 复习资料 / 其他。
5. **附件**：把文件拖进框里，最多 5 个、每个不超过 50MB（zip 不超过 20MB）。手机加不上附件 → 走路线 1。
6. 勾选「文件里不含本人或他人的姓名、学号、手机号、身份证号」→ **Submit new issue**。
7. 维护者确认后加 `approved` → 机器人按表单归档、检查通过后自动合并。你不需要 Fork、不需要知道路径、不需要改 `INDEX.md`。

**常见卡点**
- **没权限点 Add file**：正常，你不是仓库成员；这条路根本不用点 Add file。
- **手机能不能传附件**：GitHub 手机网页对附件支持不稳定；加不上就走路线 1 私发。
- **表单里课程名写错**：机器人找不到课程目录会失败，Issue 被标「入库失败」；把课程名改成与文件夹完全一致，维护者移除标签后再加 `approved` 即可。

## 路线 1：直接把文件发给维护者（备选）

1. 在班级/学院群问一句「课程资料库谁来收资料」，或开 Issue 留言。
2. 写清四件事：**课程全名 + 学院/专业 + 年份学期 + 资料类型**。
3. 文件直接发过去；维护者替你命名、放目录、提交。
4. 发之前检查：含姓名、学号、手机号、身份证的页先删掉或涂掉。

**常见卡点**
- **没权限点 Add file**：你不用点，维护者代传。
- **手机能不能传附件**：能发微信/邮件就能传；超大文件给网盘链接。
- **表单里课程名写错**：这条路不填表单；如果你同时开了 Issue，维护者会按正确课名处理。

## 路线 2：Fork + Pull Request（备选 · 进阶，可选）

1. 官方仓库右上角 **Fork** → 你账号下多一份副本。
2. 在**你自己的副本**里进目标文件夹 → **Add file** → **Upload files** → **Commit changes**。
3. 回官方仓库 → **Pull requests** → **New pull request** → 选你的分支 → **Create pull request**。
4. 维护者审核合并。全程网页，不用命令行；一般 5~10 分钟。

**常见卡点**
- **没权限点 Add file**：先确认你是在自己的 Fork 里，不是在官方仓库。
- **手机能不能传附件**：手机网页上传容易失败，建议用电脑；或改走路线 0 / 1。
- **表单里课程名写错**：这条路不用表单；PR 里路径或课名写错，会被要求改。

## 路线 3：本地 git（备选 · 开发者用）

```bash
git clone https://github.com/7620qwertqwert-beep/course-vault.git
cd course-vault
# 放好文件后
git add .
git commit -m "add: 高等数学 2025秋 期末A卷"
git push   # 没权限就推到自己的 fork，再开 PR
```

**常见卡点**
- **没权限点 Add file**：git 也一样，官方仓库无写权限；推到自己的 fork 再开 PR。
- **手机能不能传附件**：不建议手机跑 git；用电脑，或改走路线 0。
- **表单里课程名写错**：这条路不用表单；目录或文件名写错会被 CI 拦下。

## 最后三句

- 传错了想删：文件页右上角垃圾桶 → Commit；但历史里仍有，含个人信息的要走[下架流程](../TAKEDOWN.md)。
- 老师明确不许外传的课件/试卷不要传；教材只登记信息，不传 PDF。
- 笔记丑没关系，标出「老师说了必考」的那一页最值钱。
