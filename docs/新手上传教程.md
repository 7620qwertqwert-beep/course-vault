# 新手上传教程：第一次上传，照着点就行

> 前提：不用会 Git，也不用 Fork。**主通道是网页上传**：http://82.156.233.65:8080/docs/upload.html ，选课、拖文件、提交就行。只有网页上传失败、或需要公开记录时才用下文的 Issue 表单。上传前先记住：资料库是公开的，删文件不等于删历史；含姓名、学号、电话、身份证的页，先删掉或涂掉。

## 网页上传失败时：填「上传资料」Issue 表单（备选）

1. 打开仓库首页 → **Issues** → **New issue** → 先选你所在**学院**的模板（例如 **「上传资料 · 医学院」**）→ **Get started**。学院已经预填好；进去后先选 **所属专业**，再填 **课程名称**。
2. 按模板填：**课程名称**、**开课学院**、**所属专业**、**年份学期**、**资料类型**。
3. **课程名称** 照仓库目录写，写成 **「专业 · 课程名」** 最好认，例：`康复治疗学 · 康复医学概论`；只写课程名也能对上。**仓库里没有这门课**，说明还没建目录——开个 Issue 说一声，或先走下面的 Issue 表单 让维护者建目录。
4. **年份学期**：手填 `20xx春/秋`，例如 `2025秋`、`2023春`、`2025秋季`、`25秋`；填你实际上课的那个学期。**资料类型**：笔记 / 课件 / 试卷 / 作业 / 实验报告 / 复习资料（各对应课程下同名子目录）。
5. **附件**：把文件拖进框里，最多 5 个、每个不超过 50MB（zip 不超过 20MB）。手机加不上附件 → 走下面的 Issue 表单。
6. 勾选「文件里不含本人或他人的姓名、学号、手机号、身份证号」→ **Submit new issue**。
7. 维护者确认后加 `approved` → 机器人自动归档（网页上传不需要这一步，提交后直接进队列）。你不需要 Fork、不需要知道路径、不需要改 `INDEX.md`。

**常见卡点**
- **没权限点 Add file**：正常，你不是仓库成员；这条路根本不用点 Add file。
- **手机能不能传附件**：手机网页对附件支持不稳定；加不上就走下面的 Issue 表单 私发。
- **名字写错会怎样**：机器人不会猜着入库，而是回复最接近的写法（学院、专业、课程都会给 1~3 个候选）；照着改，维护者移除「入库失败」标签后再加 `approved` 即可。
- **课程名不知道怎么写**：照课程目录里的名字填，写成「专业 · 课程名」最好认；只写课程名也能自动核对。仓库里没有这门课就开个 Issue 说一声建目录；不要随便写成相近的课。
- **课程前缀专业和所选专业对不上**：机器人会报「课程『X』属于专业『Y』，与所选专业『Z』不一致，请重新选」，按提示改对「所属专业」或重新挑课程即可，不会猜着入库。
- **表单里课程名写错**：机器人找不到课程目录会失败，并提示本学院内最接近的课程名（带专业前缀）；重新选对后触发即可。

## 路线 1：直接把文件发给维护者（备选）

1. 在班级/学院群问一句「课程资料库谁来收资料」，或开 Issue 留言。
2. 写清四件事：**课程全名 + 学院/专业 + 年份学期 + 资料类型**。
3. 文件直接发过去；维护者替你命名、放目录、提交。
4. 发之前检查：含姓名、学号、手机号、身份证的页先删掉或涂掉。

**常见卡点**
- **没权限点 Add file**：你不用点，维护者代传。
- **手机能不能传附件**：能发微信/邮件就能传；超大文件给网盘链接。
- **表单里课程名写错**：这条路不填表单；如果你同时开了 Issue，维护者会按正确课名处理。

## 路线 2：Fork + Pull Request（备选 · 进阶，可选）

1. 官方仓库右上角 **Fork** → 你账号下多一份副本。
2. 在**你自己的副本**里进目标文件夹 → **Add file** → **Upload files** → **Commit changes**。
3. 回官方仓库 → **Pull requests** → **New pull request** → 选你的分支 → **Create pull request**。
4. 维护者审核合并。全程网页，不用命令行；一般 5~10 分钟。

**常见卡点**
- **没权限点 Add file**：先确认你是在自己的 Fork 里，不是在官方仓库。
- **手机能不能传附件**：手机网页上传容易失败，建议用电脑；或改走网页上传 / 1。
- **表单里课程名写错**：这条路不用表单；PR 里路径或课名写错，会被要求改。

## 路线 3：本地 git（备选 · 开发者用）

```bash
git clone https://gitee.com/youliboshi/course-vault.git
cd course-vault
# 放好文件后
git add .
git commit -m "add: 高等数学 2025秋 期末A卷"
git push   # 没权限就推到自己的 fork，再开 PR
```

**常见卡点**
- **没权限点 Add file**：git 也一样，官方仓库无写权限；推到自己的 fork 再开 PR。
- **手机能不能传附件**：不建议手机跑 git；用电脑，或改走网页上传。
- **表单里课程名写错**：这条路不用表单；目录或文件名写错会被 CI 拦下。

## 最后三句

- 传错了想删：文件页右上角垃圾桶 → Commit；但历史里仍有，含个人信息的要走[下架流程](../TAKEDOWN.md)。
- 老师明确不许外传的课件/试卷不要传；教材只登记信息，不传 PDF。
- 笔记丑没关系，标出「老师说了必考」的那一页最值钱。
