# 📖 官方核心课程对照表

> **数据来源**：信阳师范大学招生信息网「专业介绍」栏目（各学院页面公布的「核心课程」）。
> **用途**：告诉你这个专业官方认定的核心课是哪些、仓库里有没有建目录——找资料、补目录都照这张表来。
> **怎么读**：✅ = 仓库已有这门课的目录（可以上传资料）；➕ = 官方列了但这门课还没建目录（开 Issue 说一声就补）。
> 
> ⚠️ 没被列进「核心课程」的课**不代表不重要**，只代表招生网没写。学分、学时、任课教师官网不公布，卡片里仍是「待补充」，等上过课的人补。
